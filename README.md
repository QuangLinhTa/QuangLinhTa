### ✨ About Me

DevOps Engineer with **3+ years** of experience administering shared CI/CD platforms (Jenkins, GitHub Actions) for **20+ projects and 600+ users**. Hands-on with Ansible build machine automation, OpenBao secrets management, and Python-based CI/CD tooling shared across pipelines.

#### 🛠 My Personal Project Story

- [**AWS DevOps Platform Engineering**](https://github.com/aws-sample-project/aws-sample-platform): A multi-environment (dev, staging, production) AWS setup built end to end.
  - **Terraform:** modular configurations with remote state in S3.
  - **Containers:** UI, Catalog and Cart services of the AWS Retail Store Sample App, built with Docker and published to ECR.
  - **Deployment:** ECS Fargate behind an ALB, with security groups controlling traffic between components.
  - **Access and logging:** IAM Identity Center permission sets with least privilege, plus per-container CloudWatch Logs.

- [**S3 Sync Service**](https://github.com/QuangLinhTa/aws-s3-sync): A service that syncs an S3 prefix, compresses it, and serves the archive with a status endpoint.
  - **Sync service:** Python script that syncs an S3 prefix to `archive.tar.gz` and publishes it with `status.json` through Nginx. It runs in a loop (configurable interval) or once.
  - **Containers:** Docker image, with short-lived AWS SSO credentials for local runs.
  - **Kubernetes:** Helm chart for EKS (3 replicas, pod anti-affinity) wrapped by a Terraform module, using IRSA for AWS access.
